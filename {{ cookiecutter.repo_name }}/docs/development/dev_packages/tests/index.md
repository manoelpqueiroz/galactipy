# Custom Test Objects

In order to run the test suite
either more efficiently
or enable testing at all,
the project implements
specific objects
used only inside test contexts.

Some of the objects are used
to streamline test operations
and reduce duplicate or verbose code,
while others are custom objects
that are required
so specific tests can be run.

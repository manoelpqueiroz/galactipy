# CLI Helpers

To make usage of {{ cookiecutter.project_name }}
easier on the command-line,
additional objects are implemented.
These classes and functions
serve one or more
of the following roles:

- Smoothen the user experience
  by applying straightforward visual feedback
  to the terminal;
- Polish the interface
  between user input
  and program execution,
  avoid dissonance
  between what a user expects the program
  to interpret
  and how it actually behaves;
- Offer additional capabilities
  and customisation options
  for the program.

They are referenced in this section
so contributors can understand
those objects' specific purpose.

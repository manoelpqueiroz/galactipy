A compiled [`re`][1] object
that can be used to parse log files
generated by {{ cookiecutter.project_name }}.

The expression is described below:

```py
r"""
  (?P<ts>\d{4}-\d{2}-\d{2}\s\d{2}:\d{2}:\d{2}.\d{3})
  \s\|\s
  \d:\d{2}:\d{2}.\d{6}
  \s\|\s
  (?P<level>\w+)
  \s+\|\s
  (?P<module>\w+)\.py:(?P<line>\d+)
  \s+\|\s
  (?P<message>\S.*?)
  \s*¶
"""
```

Extra content is not captured
with this expression,
as we recommend parsing those
directly from the `app.jsonl` log file
which is generated concurrently
with any logs for {{ cookiecutter.project_name }}.
